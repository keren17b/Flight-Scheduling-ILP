# LEG_02_27 diagnosis

Diagnosed on 2026-10-04 using the current production input and legality settings.

**The flight is individually coverable, but the current model cannot cover it together with LEG_01_28.** Exact search found 57,137 closed duty paths containing LEG_02_27. The current production initial pool contains 10 of them, among 1,298 total columns. Therefore an artificial value of 1 does not mean no column containing the flight was generated; it means selected real columns provide zero coverage for that flight.

Input: `data/generated/week_1_with_padding.csv`, SHA-256 `1b36221d887a443dd78e51696978753c27355680e13d709b5ea50647ddf33d3e`. Production rules: connections 30 minutes to 8 hours; duty elapsed time at most 12 hours, actual flying at most 8 hours, at most 5 flights; between-duty rest 10 to 48 hours; pairings at most 5 days and 5 duties, returning to their starting crew base.

**A valid existing pairing** has two duties, each containing one flight:

| Duty | Flight | Route | Departure | Arrival |
|---|---|---|---|---|
| D152 | LEG_01_30 | BASE2 → AIR12 | Jan 1, 12:59 | Jan 1, 15:46 |
| D362 | LEG_02_27 | AIR12 → BASE2 | Jan 2, 13:45 | Jan 2, 16:34 |

Rest is 21h59m, total pairing elapsed time is 27h35m, and the production cost is 21.983333 hours. This is the cheapest pairing containing the target under current rules.

**The bottleneck is LEG_01_30.** Exact checks, without pricing budgets or Top-K pruning, found:

| Search | Closed pairing paths |
|---|---:|
| Contains LEG_02_27 | 57,137 |
| Contains LEG_02_27 without LEG_01_30 | 0 |
| Contains LEG_01_28 | 712,493 |
| Contains LEG_01_28 without LEG_01_30 | 0 |
| Contains both LEG_02_27 and LEG_01_28 | 0 |

Every pairing covering either return must use LEG_01_30, and no pairing can cover both returns. LEG_01_30 is required and can be covered only once. If `c_f` denotes real coverage and `a_f` its artificial variable:

```
c_LEG_02_27 + c_LEG_01_28 <= c_LEG_01_30 <= 1
c_LEG_02_27 = 1 - a_LEG_02_27
c_LEG_01_28 = 1 - a_LEG_01_28

Therefore a_LEG_02_27 + a_LEG_01_28 >= 1.
```

This holds even with all legal columns and fractional LP selection. More iterations, a larger artificial penalty, or exhaustive pricing cannot remove this conflict under the current input and rules.

**Why the natural same-day outbound is rejected:** LEG_02_25 departs BASE2 at 01:04 and reaches AIR12 at 03:46. LEG_02_27 departs AIR12 at 13:45. The gap is 599 minutes, while the minimum rest is 600 minutes. Combining them in one duty also fails: the gap exceeds the 8-hour connection maximum and the duty would span 15h30m, exceeding 12 hours. The later outbound, LEG_02_30, arrives at 15:46, after the target has departed. The only usable earlier outbound in the input is LEG_01_30, which is also the only supply for LEG_01_28.

**Why a dual of 1,000,000 is insufficient:** production pricing computes `pairing_cost - sum(all_flight_duals)`, not just cost minus the target's dual. The compulsory outbound may carry a large negative dual. An illustrative feasible dual certificate has:

```
LEG_02_27: +1,000,000
LEG_01_28: +1,000,000
LEG_01_30:   -999,998.766667
all other flights: 0
```

For this vector the exact minimum reduced cost of a target pairing is +20.75, so none improves the LP. This vector is a mathematical example, not an observed dual vector from the user's run. Production pricing was run with two synthetic vectors: target-only +1,000,000 produced 100 target columns; the bottleneck certificate produced zero negative columns. The infeasibility proof does not require an LP solver. Subsequent full optimization experiments use a workspace-local MOSEK installation and the existing license; see `rest_9h58/summary.json` and `delay_one_minute/summary.json`.

**Ways to cover the flight:**

1. If 9h59m rest is an intended permissible rule, changing the diagnostic graph's minimum rest to 599 minutes admits `LEG_02_25 → LEG_02_27`. The two-duty witness has 9h59m rest and is disjoint from `LEG_01_30 → LEG_01_28`. This hypothetical test found 739,169 target paths.
2. If 10 hours is mandatory, a hypothetical one-minute delay of LEG_02_27, shifting departure to 13:46 and arrival to 16:35, admits that same pairing with exactly 10 hours rest. It is also disjoint from the competitor witness. This test found 669,085 target paths. Check whether the real timestamps need correction before changing input data.
3. With fixed times and the strict rest rule, additional crew supply at AIR12 is necessary: genuine pre-horizon positioning, an initial crew state, or a separately modeled deadhead. The current pairing model only permits crews to originate at a base and travel via operating flights. Padding Jan 8–10 cannot supply a crew for Jan 2. Simply allowing the same operating flight to be covered twice changes the exact-coverage model and is not a repair within its current assumptions.

The initial exact timing tests demonstrate removal of this particular conflict. A subsequent full run with 9h58m rest produced a binary solution covering all 234 required flights exactly once, using 72 pairings at cost 821.716667. Delaying only LEG_02_27 leaves another AIR12 supply bottleneck: LEG_03_25 to LEG_03_27 still has 9h59m rest. Production data and configuration were not edited.
